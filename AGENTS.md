# Working on com-rs with a coding agent

The instructions live in [CLAUDE.md](CLAUDE.md), whatever the agent: the two rules of
the architecture (dependencies point downward, placement by function), what to read
before adding a function or a block ([docs/API.md](docs/API.md), the generated index of
every public item, and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)), how a feature is
validated against its reference, and the checks to run before declaring a task done
(`just check`).
