comrs
=====

**Link-level simulation of digital communication systems, wireless and optical.**

``comrs`` is the Python interface of `com-rs <https://github.com/com-rs/com-rs>`_:
the blocks of a digital or optical link — sources, constellations, pulse shaping,
channels, fibre propagation, devices, receiver DSP and metrics — implemented in Rust
and driven from Python with NumPy arrays. Monte Carlo campaigns run on every core with
reproducible random streams, and their results come with confidence intervals.

.. highlights:start
.. highlights: generated by tools/highlights.py, do not edit

- **Lightweight**: one run-time dependency in Python (numpy), 9 direct crates in Rust and no C, C++ or Fortran library to build; 27 MB installed with its dependencies (the benchmark's environment: komm 22 MB, OptiCommPy 321 MB, Sionna 1004 MB).
- **Fast**: compiled Rust, Monte Carlo runs on every core; on one CPU thread, the links of the benchmark take 2.1 to 33 times as long with komm, 2.3 to 4.7 times as long with OptiCommPy and 1.1 to 7.4 times as long with Sionna as with com-rs.
- **Safe**: ``unsafe`` code forbidden in every crate, invalid inputs are errors (one error type), results independent of the thread count; 473 unit tests, 144 validation tests, 215 Python tests.
- **Validated**: compared with 100 papers, standards and reference tools (62 fully reproduced, 32 partly), 54 inconsistencies found in them; 36 validation cards rerun a comparison without the paper.

The details, and how these numbers are produced: :doc:`why`.
.. highlights:end

.. code-block:: python

   import comrs

   rng = comrs.Rng(1)
   c = comrs.Constellation("qam", 16).normalized()
   bits = comrs.bits(4 * 100_000, rng)
   y = comrs.awgn_ebn0(c.modulate(bits), 10.0, 4, rng)
   comrs.ber(c.demodulate(y), bits), comrs.theory_ber(16, 10.0, "qam")
